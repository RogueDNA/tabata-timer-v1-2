TABATA TIMER V1.2
=================

This version adds:
- Louder, sharper workout beeps
- Voice timing improvements
- “Right, Get Ready to Work” about 5 seconds before work starts
- “Round 1 — Exercise Name” about 3 seconds before each round starts
- “Work” at the start of each work period
- “Time for a Rest” as the rest-period beep sounds
- “Great workout, you’re all done” when the workout finishes
- Custom exercise names for each round
- Exercise names are shown during the workout
- Saved workouts now include their exercise list
- Load and delete saved workouts
- Settings remembered by the browser

CUSTOM WORKOUTS
---------------
1. Set Work, Rest, Rounds and Preparation time.
2. Set the number of Rounds to match the number of exercises you want.
3. Enter an exercise beside each round, for example:
   1. Bicep Curls
   2. Shoulder Press
   3. Bent-Over Row
   4. Chest Press
   5. Tricep Extensions
   6. Lateral Raises
4. Enter a workout name, such as “Monday Dumbbell Workout”.
5. Select Save timer.
6. Load the saved workout whenever you want to use it again.

VOICE SEQUENCE
--------------
For a 10-second preparation period:
- Around 5 seconds remaining: “Right, Get Ready to Work”
- Around 3 seconds remaining: “Round 1 — Bicep Curls”
- At 0 seconds: beep + “Work”

During later rounds:
- Around 5 seconds before work: “Right, Get Ready to Work”
- Around 3 seconds before work: “Round 2 — Shoulder Press”
- At the work start: beep + “Work”

At the start of rest:
- Beep + “Time for a Rest”

At the end:
- Completion beeps + “Great workout, you’re all done”

DEFAULT TIMER
-------------
Work: 20 seconds
Rest: 10 seconds
Rounds: 8
Preparation: 10 seconds

WINDOWS SETUP
-------------
1. Download the ZIP file.
2. Right-click it and choose Extract All.
3. Open the extracted folder.
4. Double-click index.html.
5. Use Start to begin the timer.

IMPORTANT
---------
Voice uses your browser/device's built-in English speech voice. The available voice and sound level can vary by device/browser. Make sure your device volume is turned up.

Saved workouts stay in this browser on this device when browser storage is available.
